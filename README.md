# Калькулятор штрафов МЧС

MVP фронтенд-проекта на чистом HTML, CSS и JavaScript.

## Структура

- `demo-page.html` - демонстрационная страница калькулятора.
- `embed.html` - минимальная страница для встраивания калькулятора.
- `css/` - стили проекта.
- `js/` - JavaScript-модули проекта.
- `docs/` - документация проекта.
- `assets/` - статические ресурсы.

## Запуск

Откройте `demo-page.html` в браузере.
